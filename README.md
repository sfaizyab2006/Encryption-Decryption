# Encryption-Decryption

A simple **Encryption and Decryption** program built with Python to practice basic programming concepts, string manipulation, and file handling.

## Features

- Encrypt text
- Decrypt encrypted text
- User-friendly menu
- Basic input handling

## Technologies Used

- Python
- OOP

## Concepts Used

- Functions
- Strings
- Loops
- Conditional Statements
- User Input
- Basic Encryption/Decryption Logic

## How to Run

1. Clone the repository.
2. Open the project folder.
3. Run the Python file:

```bash
python encryption.py
```

## Purpose

This project was created as a beginner Python project to understand how encryption and decryption work while practicing fundamental programming concepts.
